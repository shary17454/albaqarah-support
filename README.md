# البقرة — الدعم

رفيقك اليومي مع سورة البقرة.

## المساعدة

- **القراءة:** افتح «اقرأ» لعرض صفحات المصحف الأصلية، واستخدم «وقفت هنا» لحفظ موضعك.
- **الخطط:** اختر مدة الخطة وأوقاتك، ثم سجّل الإنجاز بزر «تم الورد» بعد إكمال القراءة. يمكنك إعادة توزيع المتبقي أو تأجيله للغد.
- **الاستماع:** اختر الآية أو المقطع المطلوب. تنزيل التلاوة المتصلة يحتاج اتصالًا بالإنترنت؛ القراءة والتلاوة المضمّنة متاحتان محليًا.
- **المظهر:** من الإعدادات اختر النهاري أو الليلي أو إعداد الجهاز. تبقى صور المصحف بألوان مصدرها الأصلي.
- **التفسير والوقفات:** تُتاح المواد بعد توثيقها واعتمادها؛ قد لا تتوفر مادة معتمدة لآية معينة في النسخة الحالية.

## الإبلاغ عن مشكلة

[افتح بلاغ دعم](https://github.com/shary17454/albaqarah-support/issues/new). اذكر إصدار التطبيق، ونوع الجهاز، وإصدار النظام، والخطوات التي تسببت في المشكلة. لا ترفق ملاحظاتك الخاصة أو تسجيلاتك أو بيانات شخصية في البلاغات العامة.

[سياسة الخصوصية](PRIVACY.md)

مصدر صفحات المصحف والتلاوات: [مجمع الملك فهد لطباعة المصحف الشريف](https://qurancomplex.gov.sa/). التطبيق مستقل، والمجمع مصدر للمحتوى الأصلي.
